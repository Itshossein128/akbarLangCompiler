# AkbarLang Compiler

A custom programming language and compiler project created to explore the fundamentals of language design and compiler construction.

## Overview

AkbarLang is an educational compiler project covering core concepts behind programming languages.

## Concepts Explored

- Lexical analysis
- Parsing
- Language design
- Compiler architecture
- Translating source code into executable representations

## Why This Project Matters

Compiler projects demonstrate understanding beyond frameworks and libraries by exploring how programming languages themselves are built.

## Tech Stack

- Programming language implementation tools
- Custom language design
- Compiler concepts
